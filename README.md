### 2025 在 HDU 学习数电实验的项目汇总

本仓库记录了 **数字电路与逻辑设计** 课程的全部上机实践，包含基础组合逻辑、时序逻辑以及期末综合大作业。

* **技术栈**：主要使用 **VHDL**与 **Verilog** 硬件描述语言。
* **实验重点**：不仅要求逻辑实现准确，还强调了仿真验证（Waveform）与引脚分配（Pin Planning）的严谨性。
* **个人经验**：大大方方做，等到报错了再找原因😋，数电实验内容量挺多的。一般的操作逻辑是
   * 1.先建VHDL图或写Verilog代码
   * 2.进行全编译
   * 3.如果报错对原理图进行修改，不报错则新建波形文件进行波形仿真，对输入输出端口进行Group绑定后看仿真波形是否符合波形预期
   * 4.如果不符合预期仿真波形有可能是Group输出端口时顺序错误，无误则进行远程实验平台FPGA引脚绑定，查看**远程平台操作手册.pdf**进行引脚绑定
   * 5.绑定完成后再次进行全编译输出.sof文件（一般在Output文件夹下），后面登录远程实验平台要将此文件上传进行实体验证
   * 6.登录远程实验平台进行验证

## 实验开发流程
1. **逻辑建模**：根据实验要求绘制真值表或状态转移图（FSM）。
2. **HDL 编写**：使用 VHDL 或 Verilog 描述电路行为。
3. **功能仿真**：通过 `University Program VWF` 进行波形仿真，确认逻辑无误。
4. **引脚绑定**：在 `Pin Planner` 中根据实验板卡引脚图进行映射。
5. **硬件验证**：编译并生成 `.sof` 文件，下载至 FPGA 开发板或远程平台查看现象。
